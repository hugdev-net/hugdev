# Win10 Desktop App Skeleton

基于 `Python + PySide6` 的 Win10 桌面应用骨架，主界面包含：

- 按钮区：`启动`、`停止`、`单行极速模式`
- 表单参数区：`左`、`上`、`右`、`下` 四个整数像素输入框，以及实时鼠标坐标
- 显示区：图片预览框、OCR 单行结果框、带滚动条的调试日志框

## 运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 当前行为

- 点击启动后校验截图区域
- 按输入区域从当前屏幕截取图片
- 在显示区预览截图结果
- 使用本地 CPU OCR 识别图片文字
- 默认启用 `单行极速模式`，当截图区域已经紧贴单行文本时可跳过文本检测以降低延迟
- 关闭 `单行极速模式` 后回到标准模式，执行检测 + 识别，适合多行文本或区域较松的截图
- OCR 引擎在进程内复用，避免重复加载模型
- 对 OCR 文本执行逐字清洗、去冒号、去标点和 trim
- 将清洗结果显示到单行文本框
- 自动写入系统剪贴板，便于直接粘贴
- 日志框持续输出截图耗时、OCR 推理耗时和总耗时等调试信息

## 使用建议

- 如果截图区域只包含一行、方向正常、边界比较紧，保持 `单行极速模式` 开启，速度最快
- 如果识别结果异常、漏字，先关闭 `单行极速模式` 再试一次
- 想进一步提速时，优先缩小截图区域，避免带入无关背景
