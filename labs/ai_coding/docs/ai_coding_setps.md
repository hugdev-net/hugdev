### UI 风格设计系统样例

- 样例1

```markdown
# 角色

你是一位资深的产品视觉设计师，擅长极简而有质感的界面设计。请先与我确认设计方向，再产出界面。

# 任务

为一套跨端产品建立统一的「设计语言 / Design System」，并以此渲染一组高保真界面原型。
覆盖三端：Windows 11 桌面端、macOS 桌面端、Web 网页端。
本轮目标是「定方向」——先给出设计语言总览与关键界面示意，而非堆砌所有页面。

# 设计气质（最重要，请严格遵循）

整体追求：高雅大气、超高品质、精致细节，但绝不繁杂——是有质感的、温和的。

- 风格基因：北欧极简 + 日式侘寂的克制，融入 claude.ai 官网那种温润、考究的调性。
- 用建筑作比：雅典神庙的秩序与比例 + 唐代建筑的大气稳重；明确排斥巴洛克式的繁复堆砌与浮夸装饰。
- 一句话：外形不必复杂，但用料的品质和质感必须上乘。留白即设计，克制即高级。

# 字体规范

- 字族：SF Pro 风格的无衬线字体（系统优先 SF Pro / Inter，中文用苹方或思源黑体）。
- 标题：加粗，字号层级分明，建立清晰的视觉节奏（建议 4–5 级层级）。
- 正文：清晰易读，行高舒展，字重适中（Regular / Medium）。
- 数字（时长、进度、计数等）：使用等宽 / Tabular Figures 特性，保证对齐与稳定感。

# 色彩规范

- 参考 claude.ai：以温暖的米白 / 暖灰为底，搭配低饱和的中性色，质感温和不刺眼。
- 主色克制使用，仅用于关键操作与状态；大面积留白，靠层次而非颜色撑场面。
- 不要高饱和撞色、不要花哨渐变；阴影要轻、柔、有空气感。
- 提供完整色板：背景层级（base/raised/overlay）、文本层级（主/次/弱）、主色、语义色（成功/警告/错误/信息）、分隔线，并给浅色与深

# 需求&功能

- 请参考 需求分析及功能列表.md
```

```markdown
你是一位作为资深专业的UI交互设计师，请根据需求文档内容设计一系列界面。需求：精致、优雅、沉稳的风格。  
产出：高保真设计、交互式原型；在设计一系列界面之前，请先确认整体风格方向，确保其精致、优雅且沉稳的风格。

- 语言：中文＋英文双语显示
- 视觉风格：中性米色＋深棕色（偏日式现代风格，柔和、雅致）；例如： 和风现代 × 极简风格：以米色（#f5f1ea）、墨色（#1f1a14）、金茶色（#b8975a）为主色调
- 字体设计：衬线字体标题＋无衬线体正文字体（杂志感，优雅，等宽）

- 平面化与低饱和度设计：采用简洁直线构图，减少圆角，通过边框、虚线和留白划分信息区域
- 交互程度：中等（标签切换、状态变化、预约流程跳转）
- 可调整项：配色方案切换、语言切换（中/英）
```

## 详细设计

- 接口定义：模块间通过接口调用， 优先代码级别接口类的方式，如果是跨语言那尽量采用静态或者动态库的方式，最后才考虑进程间通信或者C/S结构；整体要避免过度设计，简洁高效。
- 数据结构：模块划分和接口定义相关的数据结构要先定义清楚，反复验证其合理和完整性，尽量在后续研发中不要修改。

### 构建可视化程序

@labs/界面原型.html 是设计给出的单页版原型，
请根据这个构建项的UI， 要求直接复用设计的dom 和样式，保持产出的UI和原型的一致性。
当然需要何理的拆分为若干vue组件，还要生成与之匹配的相关数据类，然后用 vue 的状态管理 pinia 维护。
