# Windows 设备设置区域（DeviceRegion）修改与权限管理指南

## 1. 概念定义

* 设备设置区域（DeviceRegion）：指 Windows 系统在首次安装（OOBE 阶段）时记录的底层地理位置代码。它主要用于操作系统识别特定地区的功能策略（例如：欧盟纯净版功能区别）。
* 国家或地区（常规设置）：指用于 Microsoft Store（应用商店）、Xbox 商店等内容的显示和下载区域。该设置位于常规控制面板中，对部分应用商店账户有修改频率限制。

------------------------------

## 2. 修改设备设置区域（以修改为日本为例）

通过修改注册表可以强制更改系统的底层设备区域代码。

## 常用国家/地区代码参考

* 中国：45
* 日本：122
* 美国：244

## 修改步骤

1. 打开注册表编辑器：同时按下键盘上的 Win + R 键，输入 regedit，按回车键打开。
2. 定位目标路径：在注册表顶部地址栏中粘贴以下路径并按回车：

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Control Panel\DeviceRegion

3. 修改数值：双击右侧的 DeviceRegion 键值。在弹出的窗口中，将基数选择为 十进制，并在数值数据中输入目标代码（如日本输入 122）。
4. 重启设备：关闭注册表编辑器并重启电脑，使底层修改完全生效。

常见错误：如果在修改时系统弹出报错提示 “无法编辑 DeviceRegion:写入该值的新内容时出错”，
说明该注册表项受到系统最高权限（TrustedInstaller）保护，当前管理员账户没有修改权限。请参考下一章节解锁权限。

------------------------------

## 3. 注册表高级权限解锁流程

当遇到权限不足无法修改的情况时，需要先提升当前账户的权限。

## 第一步：修改所有者

1. 在注册表左侧栏，右键点击 Control Panel 文件夹，选择 权限。
2. 在弹出的窗口中，点击右下角的 高级 按钮。
3. 在高级设置窗口顶部，找到“所有者：TrustedInstaller”，点击旁边的 更改。
4. 在对象名称空白框中输入 Administrators（或当前的电脑管理员用户名），点击右侧的 检查名称，然后点击 确定。
5. （可选）若有选项，勾选“替换子容器和对象的所有者”，点击 应用。

## 第二步：添加完全控制权限

1. 回到最初的“权限”小窗口。
2. 在“组或用户名”列表中，点击选中 Administrators（或当前的管理员组/用户名）。
3. 在下方权限列表中，勾选“完全控制”后面的 允许。
4. 点击 应用，再点击 确定 保存。
5. 此时即可回到第 2 章节顺利修改 DeviceRegion 数值。

------------------------------

## 4. 安全回滚：恢复系统核心权限

修改完成后，必须将注册表权限还原至 TrustedInstaller，以防止系统关键设置被恶意软件篡改，保障系统安全。

## 步骤一：将所有者改回 TrustedInstaller

1. 右键点击 Control Panel 文件夹，选择 权限，再点击右下角的 高级。
2. 点击窗口顶部所有者旁边的 更改。
3. 在空白框中精确输入以下内容：

NT SERVICE\TrustedInstaller

4. 点击右侧的 检查名称（此时字体会自动变成带下划线的 TrustedInstaller），然后点击 确定。
5. 点击窗口下方的 应用。

## 步骤二：恢复管理员的只读权限

1. 完全关闭当前的权限窗口。
2. 重新右键点击 Control Panel 并选择 权限（此操作用于刷新刚刚修改的所有者状态）。
3. 在“组或用户名”列表中，点击选中 Administrators（或之前修改过的当前用户名）。
4. 在下方权限列表中，取消勾选“完全控制”后面的 允许。
5. 确保“读取”后面的 允许 仍然处于勾选状态。
6. 点击 应用，再点击 确定 退出。

验证方法：操作完成后，可以尝试再次双击修改 DeviceRegion。如果系统重新弹出报错提示，说明权限已成功锁死还原，系统安全得到保障。
